Runde neu starten setzt die Stufen zurück und behält die Fehlerzähler. Karten, die du nie verpatzt hast, starten dann eine Stufe höher.

Importieren

JSON einfügen oder Datei wählen. Gleiche id überschreibt den Karteninhalt und behält Stufe und Statistik.

{
  "name": "Mein Deck",
  "cards": [
    {
      "id": "stat-001",
      "tag": "L5",
      "prompt": "Definiere den p-Wert.",
      "answer": "P(Statistik so extrem | H0 wahr)",
      "distractors": ["P(H0 | Daten)", "P(Zufall)", "P(Fehler 2. Art)"],
      "explanation": "Konditioniert auf H0, nicht auf die Daten."
    }
  ]
}

Pflicht sind nur prompt und answer. Ohne distractors wird die Karte eine reine Karteikarte. Ein blankes Array [{…}] geht auch.
